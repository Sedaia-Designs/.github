## Greetings Travelers! 👋

This is the profile page for Sedaia Designs, a one person, SWE organization that works on various projects 
ranging from Blender Extensions, KTOR backed SolidJS Websites and Applications, and other little projects 
that I feel like working on

## The Team

The team is made of only one person, [Sakura Sedaia](https://github.com/SakuraSedaia), who is a self-taught, 
and novice software design engineer who got his start in high school with basic HTML/CSS websites, and is
now working on learning and developing with Kotlin and Ktor to build more advanced projects.

## Contribution

Contributing guidelines are a case by case basis, for the most part all projects allow Contributions with limitations.
As Sakura is still a developing engineer, LLM use will be restricted to orchestration, documentation and planning. 
Purely LLM Generated commits, pull requests, and issues will be ignored.

Please be sure to read the Repository's associated CONTRIBUTING.md for more information on contributing to that project.
